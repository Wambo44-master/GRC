# MaishaBora GRC Portfolio

## About This Repository

This repository contains GRC artifacts I have built as part of my self-study journey into health tech Governance, Risk, and Compliance (GRC). 

**My Background:**
- Physiotherapist with clinical understanding of patient data and workflows
- AWS Certified Cloud Practitioner (AWS CCP)
- Studied KCNA (Kubernetes and Cloud Native)
- Pivoting into Health Tech GRC

## About MaishaBora

MaishaBora is a fictional physiotherapy clinic with 50 employees treating over 100 patients per week. All policies and artifacts are built for this fictional organization to demonstrate real-world GRC implementation.

## Artifacts Included

| Artifact | Description | Frameworks Mapped |
| :--- | :--- | :--- |
| Access Control Policy | Policy for granting and reviewing access to systems containing ePHI | NIST CSF PR.AA-01, HIPAA § 164.312(a)(1) |
| User Access Review Policy | Process for quarterly access reviews | NIST CSF PR.AA-01 |
| Access Review Log | Mock quarterly access review evidence | NIST CSF PR.AA-01 |
| Controls Matrix | Mapping of controls to policies, AWS services, and evidence | NIST CSF, HIPAA |
